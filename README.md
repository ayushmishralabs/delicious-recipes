# 🍴 Delicious Recipes Website

This is a basic web development project created using only HTML and CSS. The website shows different cooking recipes in a clean and simple layout. This project was made as part of a web development assignment.

## 📌 Features

* Home page with introduction
* Multiple recipe pages (5 recipes)
* Navigation bar on all pages
* Images for each recipe
* Ingredients and step-by-step instructions
* Preparation time and difficulty level
* Simple responsive design (works on mobile)
* Hover effects on buttons
* Search bar (UI only)
* Recipe categories (Veg / Non-Veg / Dessert)

## 🛠️ Technologies Used

* HTML
* CSS

(No JavaScript used)
